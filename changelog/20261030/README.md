## Rectangular and spherical direct lights

Light adds Rectangle and Sphere kinds with full width/height or radius in world
metres, independent of node scale. Rectangles retain aiming and roll; spherical
emitters are opaque. Existing Scene/history, Inspector, guides/framing, live tuning,
automation/MCP and matching installed C++ SDK access share the same ownership and
validation. Area shadows are explicitly unsupported.

The shared renderer integrates the emitters through the pinned native public BRDF
interface using an independently authored bounded implementation. Built-in PBR
meshes, material lobes, ordinary/temporal/indirect/reflection/normal outputs,
Blend/transmission and Mesh particles use existing resource and draw queues.
Custom physically based surfaces need a capability7 rebuild;17-role archives
retain readable capabilities1–6 with unchanged bytes. Only the appended installed
Light layout changes the matching SDK fingerprint; rebuild project modules.

Gallery112 supplies two lit metal spheres and a rough receiver with editable
emitters. It adds one Scene while retaining309 prior catalog records and project
settings. Wide/tall source-free relocated renders match exactly. The manual adds
authentic shape controls and Game output, usage steps and current limits.

Focused CPU/UI/MCP/installed-SDK and software-Vulkan numerical/render checks cover
local functionality. Windows/full-editor/MSVC/FXC/cooked D3D12 and physical GPU,
input, DPI and graphical exported-game acceptance remain pending. No numbered
Windows package or dependency upgrade accompanies this local batch. The known
native shutdown allocation condition remains open and unsuppressed.
